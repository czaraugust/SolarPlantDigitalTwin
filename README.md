Gêmeo Digital Solar 
📖 Sobre o Projeto
O Gêmeo Digital é uma aplicação de simulação em tempo real desenvolvida em Python para modelar o desempenho de uma planta solar fotovoltaica. A ferramenta permite a análise da posição solar, dos níveis de irradiância e do comportamento elétrico de um arranjo fotovoltaico, servindo como uma plataforma para estudos de caso, análises de desempenho e pesquisa acadêmica.

✨ Funcionalidades Principais
Geometria Solar em Tempo Real:

Cálculo da posição solar (Elevação, Azimute, Zênite) para qualquer data, hora e localização.

Visualização gráfica da trajetória solar em um gráfico polar.

Análise de Irradiância:

Conversão de Irradiância Global Horizontal (GHI) para Irradiância no Plano do Painel (POA/GTI).

Análise comparativa em tempo real entre um painel com rastreador ideal de 2 eixos, um painel com inclinação fixa e um painel na horizontal.

Visualização de dados de irradiância em um gráfico de histórico ao longo do tempo.

Modelagem Elétrica de Módulos Fotovoltaicos

Modelagem elétrica de um sistema fotovoltaico

Geração das curvas características I x V e P x V a partir de parâmetros de datasheet.

Cálculo do Ponto de Máxima Potência (MPP) em tempo real para os três cenários de rastreamento.

Suporte para configuração de arranjos com múltiplos painéis em série e paralelo.

Interface Gráfica:

Interface com abas para uma navegação entre as diferentes análises.

Controles interativos com sliders e campos de entrada sincronizados para data, hora, localização, condições ambientais e parâmetros do sistema.

Capacidade de travar/destravar a edição dos painéis de configuração para evitar alterações acidentais.
